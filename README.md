# FMÖ Angebot

Offline-Angebotsprogramm für FMÖ Meisterbetrieb (Sanitär · Heizung · Klima).

- `index.html` – die komplette App (HTML + CSS + JS, keine Internetverbindung nötig). Einfach im Browser öffnen.
- `sw.js` – optional, macht die Online-Version (GitHub Pages) offline-fähig.
- `beispiel/` – Testdateien: `GC_DATANORM.001` (DATANORM 4, A/B/P-Sätze, CP850), `GC_DATANORM.RAB` (Rabattgruppen), `WS_DATANORM5.001` (DATANORM 5, Nettopreise), `artikel_beispiel.csv`.

Daten werden im Browser (IndexedDB) gespeichert. Regelmäßig unter *Einstellungen → Datensicherung* sichern.
